## 🔹 Зачем семантика

Семантический HTML — теги несущие **смысл**, а не просто визуальное оформление.

```html
<!-- ❌ Несемантично -->
<div class="header">
  <div class="nav">...</div>
</div>
<div class="main-content">
  <div class="article">...</div>
</div>

<!-- ✅ Семантично -->
<header>
  <nav>...</nav>
</header>
<main>
  <article>...</article>
</main>
```

**Зачем:** поисковики понимают структуру, скринридеры читают правильно, код легче читать.

---

## 🔹 Карта семантических тегов

```
<body>
 ├── <header>          — шапка страницы или секции
 │     └── <nav>       — навигационные ссылки
 ├── <main>            — основной контент (один на странице)
 │     ├── <article>   — самостоятельный материал (пост, новость)
 │     ├── <section>   — тематическая секция с заголовком
 │     └── <aside>     — боковая панель, дополнительный контент
 └── <footer>          — подвал страницы или секции
```

## 🔹 Текстовые семантические теги

| Тег | Смысл | НЕ путать с |
|-----|-------|------------|
| `<strong>` | Важность | `<b>` — просто жирный |
| `<em>` | Акцент, интонация | `<i>` — просто курсив |
| `<mark>` | Выделение/подсветка | `<span style="background">` |
| `<time datetime="2024-01-15">` | Дата/время | просто текст |
| `<abbr title="HyperText Markup Language">HTML</abbr>` | Аббревиатура | просто текст |
| `<cite>` | Ссылка на источник | `<a>` — ссылка для перехода |
| `<code>` | Код | `<pre>` — преформатированный текст |
| `<blockquote cite="url">` | Цитата | `<q>` — строчная цитата |

## 🔹 Заголовки — иерархия важна

```html
<h1>Единственный главный заголовок страницы</h1>
  <h2>Основной раздел</h2>
    <h3>Подраздел</h3>
      <h4>Вложенная секция</h4>
```

- `<h1>` — один на странице (SEO и accessibility)
- Не пропускать уровни (`<h2>` → `<h4>` минуя `<h3>`)
- Порядок определяет outline страницы

## 🔹 Списки

```html
<ul>                           <!-- Неупорядоченный -->
  <li>Элемент</li>
</ul>

<ol start="3" reversed>        <!-- Упорядоченный с атрибутами -->
  <li>Третий</li>
  <li>Второй</li>
</ol>

<dl>                           <!-- Список определений -->
  <dt>HTML</dt>
  <dd>Язык разметки</dd>
</dl>
```
