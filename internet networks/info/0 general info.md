##  Ключевые понятия (быстрый глоссарий)

| Термин | Расшифровка | Суть |
|--------|-------------|------|
| **OSI** | Open Systems Interconnection | 7-уровневая модель сети |
| **TCP/IP** | Transmission Control Protocol / Internet Protocol | Реальный стек протоколов интернета |
| **HTTP** | HyperText Transfer Protocol | Передача гипертекста |
| **HTTPS** | HTTP Secure | HTTP + TLS шифрование |
| **TLS** | Transport Layer Security | Протокол шифрования |
| **DNS** | Domain Name System | Перевод домена → IP |
| **DHCP** | Dynamic Host Configuration Protocol | Автоматическая выдача IP |
| **IP** | Internet Protocol | Адрес устройства в сети |
| **MAC** | Media Access Control | Физический адрес сетевой карты |
| **URL** | Universal Resource Locator | Адрес ресурса в интернете |
