#  Сетевые устройства: Хаб, Коммутатор, Маршрутизатор

> **Теги:** #networks #devices #конспект  

> [!abstract] Связи
> [[main]] | [[main Internet Networks]]

> [!abstract] Суть
> Три типа устройств для построения сетей. Отличаются **«интеллектом»** — уровнем модели OSI, на котором работают.

## Сравнительная таблица

| | Хаб (Hub) | Коммутатор (Switch) | Маршрутизатор (Router) |
|--|-----------|---------------------|------------------------|
| **Уровень OSI** | L1 — Физический | L2 — Канальный | L3 — Сетевой |
| **Адресация** | Нет | MAC-адрес | IP-адрес |
| **Умный?** | ❌ «Тупой» | ✅ Умнее | ✅✅ Самый умный |
| **Куда шлёт данные** | Всем портам сразу | Только получателю | В другую сеть/интернет |
| **Применение** | Устарел | Локальная сеть | Выход в интернет |

## Хаб (Hub / Концентратор) ⚡

> [!note] Уровень 1 — Физический
> Хаб — максимально примитивное устройство. Никакого «мозга» нет.

```
        ┌─────────────┐
        │     ХАБ     │
        └──┬──┬──┬──┬─┘
           │  │  │  │
          ПК1 ПК2 ПК3 ПК4

Данные от ПК1 → Хаб → ПК1, ПК2, ПК3, ПК4 (всем!)
ПК2, ПК3, ПК4 смотрят: "Это мне? Нет → выбросить"
```

**Принцип работы:**
1. На вход одного порта пришли данные
2. Хаб **копирует** их и **рассылает по всем портам**
3. Каждое устройство проверяет: для меня ли это?
4. Если нет — уничтожает пакет

> [!danger] Проблемы хаба
> - **Неэффективно**: все получают чужие данные
> - **Небезопасно**: любой в сети может "подслушать" чужой трафик
> - Как если бы почтальон клал все письма в каждый почтовый ящик дома, и жильцы сами выбрасывали чужие

**Статус:** ❌ В современных сетях **не используется**. Только в музеях и учебниках.

## Коммутатор (Switch) 🔌

> [!note] Уровень 2 — Канальный
> Коммутатор знает MAC-адреса устройств и отправляет данные **только нужному получателю**.

```
        ┌─────────────────┐
        │   КОММУТАТОР    │
        │ [таблица MAC]   │
        └──┬──┬──┬──┬────┘
           │  │  │  │
          ПК1 ПК2 ПК3 ПК4

Данные от ПК1 → Коммутатор → только ПК3 (нужный получатель)
ПК2 и ПК4 ничего не получают и не знают о передаче
```

### Таблица MAC-адресов (CAM-таблица)

| MAC-адрес | Порт |
|-----------|------|
| `AA:BB:CC:DD:EE:01` | Порт 1 |
| `AA:BB:CC:DD:EE:02` | Порт 2 |
| `AA:BB:CC:DD:EE:03` | Порт 3 |

> [!info] Как коммутатор обучается?
> Коммутатор **слушает** трафик и сам заполняет таблицу: видит, что с порта 3 пришёл кадр с MAC `AA:BB:CC` — значит, это устройство на порту 3.

### Типы рассылки

| Тип | Кому идёт | Пример |
|-----|-----------|--------|
| **Unicast** | Одному получателю | Обычная передача файла |
| **Broadcast** | Всем устройствам в сети | DHCP Discover, ARP |
| **Multicast** | Группе подписанных устройств | Видеострим в локальной сети |

> [!example] Аналогии
> - **Unicast** — обычное письмо с конкретным адресатом
> - **Broadcast** — реклама на столбе, все видят
> - **Multicast** — рассылка только подписчикам рассылки

**Статус:** ✅ Используется во всех локальных сетях.

## Маршрутизатор (Router) 🗺️

> [!note] Уровень 3 — Сетевой
> Маршрутизатор — «сын маминой подруги» среди сетевых устройств. Знает топологию сети и умеет передавать данные **между разными сетями**.

```
  Локальная сеть              Интернет
┌─────────────┐          ┌───────────────┐
│ ПК1  ПК2   │          │               │
│       │    │          │  Другие сети  │
│    Switch  │◄────────►│               │
│       │    │          │               │
│   РОУТЕР   │          └───────────────┘
└─────────────┘
```

**Принцип работы:**
1. Приходит пакет с IP-адресом назначения
2. Роутер смотрит в **таблицу маршрутизации**
3. Принимает решение: переслать в свою сеть или дальше в другую
4. Передаёт пакет следующему устройству на пути

### Таблица маршрутизации

| Сеть назначения | Следующий хоп | Интерфейс |
|-----------------|---------------|-----------|
| 192.168.1.0/24 | Напрямую | eth0 |
| 10.0.0.0/8 | 192.168.1.254 | eth1 |
| 0.0.0.0/0 | 203.0.113.1 | eth2 (интернет) |

### Дополнительные функции роутера

```
Роутер = Маршрутизатор
       + DHCP-сервер (раздаёт IP)
       + DNS-сервер (или DNS relay)
       + NAT (Network Address Translation)
       + Файрвол
       + Wi-Fi точка доступа (в домашних роутерах)
```

**Статус:** ✅ Необходим для выхода в интернет и соединения сетей.

## Где какое устройство в реальной сети?

```
ИНТЕРНЕТ
    │
    │ (WAN порт)
┌───┴──────────────────┐
│       РОУТЕР         │  ← L3, IP-адресация, маршрутизация
│  + DHCP + DNS + NAT  │    между локальной сетью и интернетом
└───┬──────────────────┘
    │ (LAN порт)
    │
┌───┴──────────────────┐
│    КОММУТАТОР        │  ← L2, MAC-адресация
│      (Switch)        │    внутри локальной сети
└──┬───┬───┬───┬───────┘
   │   │   │   │
  ПК1 ПК2 ПК3 Принтер    ← Конечные устройства
```

## Физические уровни передачи

### Типы кабелей (Физический уровень)

| Тип | Скорость | Особенности |
|-----|----------|-------------|
| **Коаксиальный** | до 10 Мбит/с | Устарел, сейчас только для ТВ-антенн |
| **Витая пара** | до 10 Гбит/с | 8 проводов, 4 пары. Самый распространённый |
| **Оптоволокно** | до Тбит/с | Стеклянное волокно + свет. Максимальная скорость |

### Режимы передачи витой пары

| Режим | Пары | Направление |
|-------|------|-------------|
| **Полудуплекс** | 2 пары | Данные в каждом направлении по одной паре |
| **Дуплекс** | 4 пары | Все пары, в обе стороны — выше скорость |

```
└───────────────────────────────────────────────┘
```
