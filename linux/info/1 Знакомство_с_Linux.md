## Теория: Что такое Linux?

Linux — это **открытая операционная система** на основе Unix, созданная Линусом Торвальдсом в 1991 году. В отличие от Windows, Linux:

- Бесплатен и с открытым исходным кодом
- Используется на 90%+ серверов в мире
- Управляется через **командную строку (CLI)** — это быстрее и мощнее графического интерфейса

### Архитектура Linux

## 📁 Структура файловой системы Linux

```
/                    ← корень (root)
├── bin/             ← основные команды (ls, cp, mv…)
├── etc/             ← конфигурационные файлы
├── home/            ← домашние папки пользователей
│   └── user/
├── var/             ← логи, временные данные
├── tmp/             ← временные файлы
├── usr/             ← программы пользователя
├── dev/             ← устройства системы
├── proc/            ← виртуальная ФС (инфо о процессах)
└── root/            ← домашняя папка суперпользователя
```

> [!NOTE] Важно
> В Linux **всё является файлом**: диски, сетевые интерфейсы, процессы — всё доступно как файл в `/dev` или `/proc`.

## ⌨️ Базовые команды навигации

| Команда | Что делает | Пример |
|---|---|---|
| `pwd` | Показать текущую директорию | `pwd` → `/home/user` |
| `ls` | Список файлов | `ls -la` |
| `cd` | Сменить директорию | `cd /etc` |
| `cd ..` | На уровень выше | `cd ..` |
| `cd ~` | В домашнюю папку | `cd ~` |
| `cd -` | В предыдущую папку | `cd -` |

### Полезные флаги `ls`

```bash
ls -l      # подробный список (права, размер, дата)
ls -a      # показать скрытые файлы (начинаются с .)
ls -la     # подробный + скрытые
ls -lh     # размер в человекочитаемом формате (KB, MB)
ls -lt     # сортировка по дате изменения
```

##  Работа с файлами и директориями

| Команда | Описание | Пример |
|---|---|---|
| `mkdir` | Создать директорию | `mkdir projects` |
| `mkdir -p` | Создать вложенные директории | `mkdir -p a/b/c` |
| `touch` | Создать пустой файл | `touch file.txt` |
| `echo` | Вывести текст / записать в файл | `echo "текст" > file.txt` |
| `cat` | Показать содержимое файла | `cat file.txt` |
| `less` | Просмотр большого файла | `less /var/log/syslog` |
| `rm` | Удалить файл | `rm file.txt` |
| `rm -r` | Удалить директорию рекурсивно | `rm -r folder/` |
| `rm -rf` | Удалить без подтверждения ⚠️ | `rm -rf folder/` |
| `mv` | Переместить / переименовать | `mv file.txt /tmp/` |
| `cp` | Копировать файл | `cp file.txt backup.txt` |
| `cp -r` | Копировать директорию | `cp -r dir/ dir_backup/` |

> [!WARNING] Осторожно!
> `rm -rf` удаляет **безвозвратно** — корзины в Linux нет!

##  Просмотр содержимого файлов

```bash
cat file.txt           # вывести всё содержимое
less file.txt          # постраничный просмотр (q — выход)
head file.txt          # первые 10 строк
head -n 20 file.txt    # первые 20 строк
tail file.txt          # последние 10 строк
tail -f /var/log/syslog  # следить за файлом в реальном времени
```

## 🔍 Поиск файлов и фильтрация

### grep — поиск по содержимому

```bash
grep "слово" file.txt          # найти строки со словом
grep -i "слово" file.txt       # без учёта регистра
grep -r "слово" /etc/          # рекурсивно по директории
grep -n "слово" file.txt       # показать номера строк
grep -v "слово" file.txt       # инвертировать (исключить строки)
```

### find — поиск файлов

```bash
find / -name "*.conf"          # найти все .conf файлы
find /home -user username      # файлы конкретного пользователя
find /tmp -mtime +7            # файлы старше 7 дней
find . -size +100M             # файлы больше 100MB
```

##  Пайпы (Pipes) `|`

**Пайп** передаёт вывод одной команды на вход другой.

```
команда1 | команда2 | команда3
```

```bash
ls -la | grep ".txt"          # найти .txt файлы
cat /etc/passwd | grep root   # найти строку с root
ps aux | grep nginx           # найти процесс nginx
history | grep "git"          # найти команды с git
```

### Перенаправление вывода

```bash
echo "текст" > file.txt       # записать (перезапись)
echo "текст" >> file.txt      # добавить в конец
ls -la 2> errors.txt          # ошибки в файл
ls -la > out.txt 2>&1         # всё (вывод + ошибки) в файл
```
