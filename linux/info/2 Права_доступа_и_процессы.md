##  Теория: Модель безопасности Linux

Linux использует **дискреционное управление доступом (DAC)**. Каждый файл принадлежит:
- **Владельцу** (owner) — конкретному пользователю
- **Группе** (group) — набору пользователей
- **Остальным** (others) — все прочие

Три типа объектов в системе:

```
┌──────────┐   ┌──────────┐   ┌──────────┐
│Пользователи│  │  Группы  │   │   Root   │
│  (users)  │  │ (groups) │   │ (superuser)│
│ Личный    │  │ Общий    │   │ Всё может│
│ доступ    │  │ доступ   │   │          │
└──────────┘   └──────────┘   └──────────┘
```

##  Права доступа: Чтение, Запись, Выполнение

### Вывод `ls -l`

```
-rwxr-xr--  1  user  group  4096  Jan 1  file.txt
│└──┬───┘       │     │
│   │           │     └── группа-владелец
│   │           └── пользователь-владелец
│   └── права (owner|group|others)
└── тип (- файл, d директория, l символическая ссылка)
```

### Расшифровка прав

| Символ | Для файла | Для директории |
|---|---|---|
| `r` (4) | Чтение содержимого | Просмотр списка файлов |
| `w` (2) | Изменение файла | Создание/удаление файлов |
| `x` (1) | Запуск как программа | Вход в директорию (`cd`) |
| `-` (0) | Нет права | Нет права |

### Числовое представление

```
rwx = 4+2+1 = 7
rw- = 4+2+0 = 6
r-x = 4+0+1 = 5
r-- = 4+0+0 = 4
--- = 0+0+0 = 0
```

| Число | Права | Пример |
|---|---|---|
| `777` | Все для всех | rwxrwxrwx |
| `755` | Стандарт для программ | rwxr-xr-x |
| `644` | Стандарт для файлов | rw-r--r-- |
| `600` | Только владелец | rw------- |
| `400` | Только чтение владельцем | r-------- |

##  Команды управления правами

### `chmod` — изменить права

```bash
# Символьный синтаксис: [кто][действие][права]
chmod u+x script.sh    # добавить выполнение владельцу
chmod g-w file.txt     # убрать запись у группы
chmod o=r file.txt     # установить только чтение другим
chmod a+x script.sh    # добавить выполнение всем (a = all)

# Числовой синтаксис
chmod 755 script.sh    # rwxr-xr-x
chmod 644 file.txt     # rw-r--r--
chmod 600 secret.txt   # rw-------
chmod -R 755 folder/   # рекурсивно для всей папки
```

| Символ кто | Значение |
|---|---|
| `u` | user (владелец) |
| `g` | group (группа) |
| `o` | others (остальные) |
| `a` | all (все) |

### `chown` — изменить владельца

```bash
chown user file.txt              # сменить владельца
chown user:group file.txt        # сменить владельца и группу
chown :group file.txt            # сменить только группу
chown -R user:group folder/      # рекурсивно
```

### `umask` — маска для новых файлов

`umask` **вычитается** из прав по умолчанию:

```bash
umask          # показать текущую маску
umask 022      # установить маску (файлы: 644, папки: 755)
umask 077      # строгая: файлы только для владельца (600)
```

```
Файл по умолчанию: 666
umask:          - 022
Результат:      = 644 (rw-r--r--)
```

##  Управление пользователями

### Создание и настройка

```bash
sudo adduser username          # создать пользователя (интерактивно)
sudo useradd -m username       # создать пользователя (без диалога)
sudo passwd username           # установить/изменить пароль
sudo usermod -aG sudo username # добавить в группу sudo (права админа)
sudo usermod -l newname oldname # переименовать пользователя
sudo userdel username          # удалить пользователя
sudo userdel -r username       # удалить пользователя + домашнюю папку
```

### Информация о пользователе

```bash
whoami             # кто я
id                 # UID, GID и все группы
id username        # информация о конкретном пользователе
groups             # к каким группам принадлежу
who                # кто сейчас в системе
w                  # кто в системе + что делает
```

### Управление группами

```bash
sudo groupadd devs                  # создать группу
sudo usermod -aG devs username      # добавить в группу
sudo gpasswd -d username devs       # удалить из группы
sudo groupdel devs                  # удалить группу
cat /etc/group                      # просмотр всех групп
```

##  Специальные биты доступа

| Бит | Обозначение | Описание |
|---|---|---|
| **SUID** | `s` на позиции x у owner | Запуск от имени владельца файла |
| **SGID** | `s` на позиции x у group | Запуск от имени группы |
| **Sticky** | `t` на позиции x у others | Только владелец удаляет свои файлы (для /tmp) |

```bash
chmod u+s program    # установить SUID
chmod g+s shared/    # установить SGID на директорию
chmod +t /tmp        # sticky bit (как на /tmp по умолчанию)
chmod 4755 program   # SUID числом
```

##  Мониторинг процессов

### `ps` — статический снимок

```bash
ps                   # процессы текущей сессии
ps aux               # все процессы всех пользователей
ps aux | grep nginx  # найти процесс nginx
ps -ef               # полный формат вывода
```

Вывод `ps aux`:
```
USER   PID  %CPU %MEM    VSZ   RSS  STAT START   COMMAND
root     1   0.0  0.1  16952  1024  Ss   Jan01   /sbin/init
user  1234   0.5  1.2  45000  8192  S    10:00   nginx
```

### `top` — динамический мониторинг

```bash
top           # запустить top
```

| Клавиша в top | Действие |
|---|---|
| `k` | Завершить процесс (ввести PID) |
| `P` | Сортировка по CPU |
| `M` | Сортировка по памяти |
| `u` | Фильтр по пользователю |
| `q` | Выйти |
| `h` | Помощь |

### `htop` — удобный интерфейс

```bash
sudo apt install htop   # установить
htop                    # запустить
```

> [!TIP] htop лучше top
> `htop` показывает загрузку каждого ядра CPU, имеет цветовую схему и позволяет управлять процессами мышью.

##  Управление процессами

### Сигналы

| Сигнал | Номер | Описание |
|---|---|---|
| `SIGHUP` | 1 | Перезагрузить конфигурацию |
| `SIGINT` | 2 | Прервать (как Ctrl+C) |
| `SIGTERM` | 15 | Вежливо завершить процесс |
| `SIGKILL` | 9 | Принудительно убить (нельзя перехватить) |

### Команды завершения

```bash
kill PID              # SIGTERM (вежливо)
kill -9 PID           # SIGKILL (принудительно)
kill -15 PID          # SIGTERM (явно)
kill -1 PID           # SIGHUP (перезагрузить конфиг)

killall nginx         # завершить все процессы с именем nginx
pkill fire            # завершить процессы, содержащие "fire" в имени
pkill -u username     # завершить все процессы пользователя
```

### Фоновые процессы

```bash
command &             # запустить в фоне
Ctrl+Z                # приостановить текущий процесс
bg                    # продолжить в фоне
fg                    # вернуть на передний план
jobs                  # список фоновых заданий
nohup command &       # запустить, не завершая при выходе из сессии
```

##  Схема жизненного цикла процесса

```
       fork()
         │
    ┌────▼────┐
    │ Running  │ ──── Ctrl+Z ──→ Stopped
    └────┬────┘
         │ wait()           
    ┌────▼────┐
    │ Zombie   │ ← родитель не забрал статус выхода
    └─────────┘
```

```
SIGTERM → процесс может поймать и завершиться корректно
SIGKILL → ядро убивает немедленно, процесс не может перехватить
```
