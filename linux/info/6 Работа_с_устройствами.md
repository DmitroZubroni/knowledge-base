##  Теория: Файловая система как основа всего

В Linux **всё является файлом**:
- Диски и разделы: `/dev/sda`, `/dev/sdb1`
- Устройства: `/dev/tty`, `/dev/null`
- Процессы: `/proc/1234`
- Сетевые сокеты, принтеры — тоже файлы

### Дерево устройств

```
/dev/
├── sda          ← первый диск (SATA/SCSI/SSD)
│   ├── sda1     ← первый раздел
│   ├── sda2     ← второй раздел
│   └── sda3     ← третий раздел
├── sdb          ← второй диск (например, USB)
│   └── sdb1
├── nvme0n1      ← NVMe SSD
│   ├── nvme0n1p1
│   └── nvme0n1p2
├── sr0          ← DVD-привод
├── null         ← "мусорник" (всё, что туда пишется — исчезает)
├── zero         ← бесконечный источник нулей
└── random       ← генератор случайных чисел
```

##  Файловые системы

| ФС | Команда создания | Применение |
|---|---|---|
| **ext4** | `mkfs.ext4` | Стандарт Linux, большинство серверов |
| **xfs** | `mkfs.xfs` | Высокая производительность, большие файлы |
| **btrfs** | `mkfs.btrfs` | Снапшоты, RAID, современные функции |
| **vfat/FAT32** | `mkfs.vfat` | Обмен с Windows/macOS, флешки |
| **ntfs** | `mkfs.ntfs` | Совместимость с Windows |
| **exfat** | `mkfs.exfat` | Большие флешки (>32GB), кросс-платформа |

## 🔍 Просмотр устройств и разделов

### `lsblk` — список блочных устройств

```bash
lsblk              # дерево дисков и разделов
lsblk -f           # с типами ФС и UUID
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINT,UUID  # нужные столбцы
```

Вывод:
```
NAME   MAJ:MIN RM  SIZE RO TYPE MOUNTPOINT
sda      8:0    0   50G  0 disk
├─sda1   8:1    0    1G  0 part /boot
├─sda2   8:2    0   20G  0 part /
└─sda3   8:3    0   29G  0 part /home
sdb      8:16   1    8G  0 disk
└─sdb1   8:17   1    8G  0 part /mnt/usb
```

### `blkid` — идентификация устройств

```bash
sudo blkid                    # все устройства с UUID
sudo blkid /dev/sda1          # конкретный раздел
```

> [!NOTE] Зачем UUID?
> UUID стабилен — он не меняется при перезагрузке, в отличие от имени `/dev/sda`, которое может измениться. Именно UUID используется в `/etc/fstab`.

### `df` — использование дискового пространства

```bash
df -h              # в человекочитаемом формате
df -H              # с единицами 1000 (не 1024)
df -T              # с типом ФС
df /home           # только для /home
```

### `du` — размер директорий

```bash
du -h /var/log              # размер директории
du -sh /var/log             # суммарно
du -sh /*                   # размер каждой папки в корне
du -h --max-depth=1 /var    # только первый уровень
du -sh * | sort -h          # отсортировать по размеру
```

##  Работа с файловыми системами

### Создание ФС (`mkfs`)

```bash
sudo mkfs.ext4 /dev/sdb1         # форматировать в ext4
sudo mkfs.ext4 -L "MyDisk" /dev/sdb1  # с меткой
sudo mkfs.xfs /dev/sdb1          # в XFS
sudo mkfs.vfat /dev/sdb1         # в FAT32
sudo mkfs.ntfs /dev/sdb1         # в NTFS
```

> [!WARNING] Форматирование удаляет все данные!
> Убедитесь, что указываете правильное устройство.

### Проверка ФС (`fsck`)

```bash
sudo fsck /dev/sdb1              # проверить и исправить
sudo fsck -y /dev/sdb1           # авто-исправление без вопросов
sudo fsck -n /dev/sdb1           # только проверка, без исправлений
sudo fsck -t ext4 /dev/sdb1      # явно указать тип ФС
sudo e2fsck -f /dev/sda1         # принудительная проверка ext2/3/4
```

> [!WARNING]
> `fsck` запускается только на **отмонтированном** разделе!

##  Монтирование устройств

### `mount` — подключить

```bash
# Синтаксис: mount [опции] <устройство> <точка монтирования>
sudo mount /dev/sdb1 /mnt/usb              # смонтировать
sudo mount -t ext4 /dev/sdb1 /mnt/data    # указать ФС явно
sudo mount -t vfat /dev/sdb1 /mnt/flash   # FAT32
sudo mount -o ro /dev/sdb1 /mnt/data      # только чтение
sudo mount -o remount,rw /                # перемонтировать с записью

# Посмотреть смонтированные ФС
mount                   # все
mount | grep sdb        # фильтр
cat /proc/mounts        # то же самое

# Создать точку монтирования
sudo mkdir /mnt/usb
```

### `umount` — отключить

```bash
sudo umount /mnt/usb          # по точке монтирования
sudo umount /dev/sdb1         # по устройству
sudo umount -l /mnt/usb       # "ленивое" — отсоединить как только освободится
```

### Если `umount` не работает (device is busy)

```bash
fuser -v /mnt/usb             # кто использует устройство
fuser -km /mnt/usb            # принудительно завершить процессы
lsof /mnt/usb                 # список открытых файлов
```

##  `/etc/fstab` — автомонтирование

`/etc/fstab` — файл, определяющий, что и куда монтировать при загрузке.

```bash
sudo nano /etc/fstab
```

### Формат записи

```
<устройство>  <точка>  <ФС>  <опции>  <dump>  <pass>
UUID=abc123   /        ext4  defaults  0       1
UUID=def456   /home    ext4  defaults  0       2
UUID=ghi789   swap     swap  sw        0       0
/dev/sdb1     /mnt/data  ext4  defaults,nofail  0  0
```

| Поле | Описание |
|---|---|
| `UUID=...` | Устройство (лучше UUID, не /dev/sdX) |
| `/mnt/data` | Точка монтирования |
| `ext4` | Тип ФС |
| `defaults` | Стандартные опции rw,suid,dev,exec,auto,nouser,async |
| `nofail` | Не прерывать загрузку если диск отсутствует |
| `0` (dump) | 0 = не включать в резервное копирование |
| `1` (pass) | Порядок проверки fsck (1=корень, 2=остальные, 0=не проверять) |

```bash
sudo mount -a    # смонтировать всё из fstab (проверка после правки)
```

##  Работа с разделами

### `fdisk` — MBR/GPT разделы

```bash
sudo fdisk -l                   # список всех дисков и разделов
sudo fdisk /dev/sdb             # интерактивный режим
```

Команды в fdisk: `n` — создать, `d` — удалить, `p` — вывести, `w` — записать, `q` — выйти.

### `gdisk` — только GPT

```bash
sudo gdisk /dev/sdb             # GPT-разделы
```

### `parted` — универсальный

```bash
sudo parted -l                  # список разделов
sudo parted /dev/sdb            # интерактивный режим
```

##  Полезные утилиты

```bash
# Создать образ диска
sudo dd if=/dev/sda of=/backup/disk.img bs=4M status=progress

# Клонировать диск
sudo dd if=/dev/sda of=/dev/sdb bs=4M status=progress

# Проверить S.M.A.R.T. диска
sudo apt install smartmontools
sudo smartctl -a /dev/sda

# Посмотреть тип ФС файла
file /path/to/file

# Проверить inode'ы (df -i)
df -i
```

## 📊 Схема: процесс подключения нового диска

```
1. Подключить диск физически
         │
2. lsblk → найти новый диск (например, /dev/sdb)
         │
3. sudo fdisk /dev/sdb → создать раздел
         │
4. sudo mkfs.ext4 /dev/sdb1 → создать ФС
         │
5. sudo mkdir /mnt/data → создать точку монтирования
         │
6. sudo mount /dev/sdb1 /mnt/data → смонтировать
         │
7. sudo blkid /dev/sdb1 → получить UUID
         │
8. Добавить в /etc/fstab → автомонтирование
         │
9. sudo mount -a → проверить
```
