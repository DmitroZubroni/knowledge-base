## на устройстве к которому получаем доступ 

выполняем 

```bash
// устанавливаем набор инструментов для удалённого доступа 
sudo apt install openssh-server -y
```

```bash
// набор консольных утилит для администрирования сети
sudo apt install net-tools
```

---

```bash 
// запускаем сервер удалёного доступа
service ssh start
```

он будет слушать все запросы адресованные на 22 порт

```bash
// проверяем статус 
service ssh status
```

---

```bash 
// узнаём апи наего компьютера
ifconfig
```

==flags=4163<UP,BROADCAST,RUNNING,MULTICAST>==

смотрим апи именно у данного флага

## На устройстве с которого управляем

выполняем 

```ping
// проверяем доступность соединение
ping 192.168.1.12
```

```bash
// выполняем подключение
ssh имяПользователя@апи
```

после того как указывается пароль, терминал переключается на терминал того устройста к которому было совершено подключение
